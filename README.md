# ToyXona.uz – To‘yxona band qilish platformasi

Ushbu loyiha to‘yxonalarni onlayn band qilish, bandlik taqvimini boshqarish va to‘lovlarni integratsiya qilish jarayonlarini namoyish etuvchi konseptual landing sahifani o‘z ichiga oladi. Sahifa texnik topshiriqda ko‘rsatilgan asosiy rollar (mehmon, vendor, administrator), funksiyalar va arxitektura bo‘yicha batafsil tasnifni taqdim etadi.

## Loyiha tarkibi
- **index.html** – Asosiy sahifa va kontent bloklari
- **styles.css** – Zamonaviy, mobilga mos dizayn
- **script.js** – Bandlik taqvimi va aloqa formasining interaktivligi

## Ishga tushirish
1. Repozitoriyani klonlang yoki yuklab oling.
2. `index.html` faylini brauzerda oching.

Sahifa statik bo‘lib, qo‘shimcha qurilmalar yoki server talab etilmaydi.
