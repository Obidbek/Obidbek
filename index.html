Bronlash jarayoni

  1. 1-qadam: Sana va slot

    Taqvimdan bo‘sh kunni tanlang. Platforma real vaqt rejimida bandlikni tekshiradi va slotni 15 daqiqaga zaxiraga oladi.

  2. 2-qadam: Paket va ma’lumot

    Paket, smena va qo‘shimcha xizmatlarni tanlang. Kontakt ma’lumotlarini kiriting va shartnoma bilan tanishing.

  3. 3-qadam: To‘lov

    Click, Payme, Uzum yoki Apelsin orqali to‘lov qiling. Stripe/PayPal integratsiyasi ham mavjud. To‘lovdan so‘ng email/SMS/Telegram tasdiqlari yuboriladi.

Integratsiyalar va API

Texnologiyalar steki

Frontend: Next.js + TailwindCSS + Zustand. Backend: NestJS, PostgreSQL, Redis, S3. CI/CD: Docker, GitHub Actions, Kubernetes.

API xavfsizligi uchun WAF va rate limit, Redis sessiyalar. CDN sifatida Cloudflare ishlatiladi.

Ma’lumotlar modeli

Asosiy jadvallar

  • users – foydalanuvchilar roli, aloqa ma’lumotlari, til
  • vendors – KYC ma’lumotlari va rekvizitlar
  • venues – lokatsiya, sig‘im, narx va reyting
  • bookings – sana, smena, paket, to‘lov statusi
  • payments, reviews, audit_logs

Unikal cheklovlar

PostgreSQL EXCLUDE constraint bandlikda takrorlanishning oldini oladi. Redis asosidagi distributed lock tranzaksiyalar davomida xavfsiz muhit yaratadi.

GDPR mosligi va maxfiylik siyosatlari foydalanuvchi so‘rovlariga binoan ma’lumotlarni o‘chirish imkonini beradi.
